# 자료·출처·기준시점

## 공개 저장소

코드·설명·설정·합성 입력 단위검사를 공개 대상으로 준비함. SGIS 등 원자료와 위치지도·파생자료의 공개 가능 범위는 해당 이용조건을 별도 확인해야 하므로 기본 제외함. 로그인·API 키·계정 정보는 코드와 노트북에 포함하지 않음. 저장소 생성·공개 게시를 이 코드가 수행하지 않음.
