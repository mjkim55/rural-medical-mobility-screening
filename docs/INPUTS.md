# 입력자료 계약과 추가 확보 목록

## 실행에 필요한 공통 입력

`data/inputs/`는 공개 업로드 대상이 아님. 공식 출처의 이용조건을 확인한 뒤 원자료를 별도로 배치함.

| 파일 | 실제 열·레이어 | 단위·주의 |
| --- | --- | --- |
| national_base.csv | `HDCD`, `HDCD_SD_NM`, `HDCD_SGG_NM`, `HDCD_EMD_NM`, `total_population`, `elderly_population`, `area_km2`, KTDB 시설별 열 | 2023년 읍면동, 점수·군집·선별값은 입력하지 않음 |
| national_boundary.gpkg | `HDCD`, `ADM_NM`, `geometry` | SGIS 2023년 4분기, EPSG:5179 |
| primary_care.gpkg | `암호화요양기호`, `요양기관명`, `종별코드명`, `시군구코드명`, `geometry` | HIRA 2025.12, 의원·보건소·보건지소·보건진료소 |
| pharmacy.gpkg | 위와 같은 열 | HIRA 2025.12 약국 |

원자료부터 실행할 때는 `prepare_inputs.py --mode raw`를 사용함. `prepared` 모드는 기존 결합표의 원변수만 읽는 대안이며 원자료 재결합과 구분해 기록함. 인증키·로그인 정보는 필요하지 않으며 자동 수집하지 않음.

## 격자 분석에 필요한 지역별 입력

- `config.json`의 각 사례에 지정된 `*_population.gpkg`: SGIS **1km 격자 폴리곤** 및 `grid_id`, `total_population`, `elderly_population`. 좌표계가 있어야 하며, 가능하면 `population_status`, `population_year`를 포함함.
- 인구표만 받은 경우 `national_grid_population_2024.csv`와 공식 격자 폴리곤을 **실제 `grid_id`로 일대일 결합**한 후 사용함. 격자 ID에서 임의로 좌표를 추정하지 않음.
- `*_stops.csv`: 실제 TAGO 형식의 `gpslati`, `gpslong`, `nodeid`, `nodenm`. 정류장 ID는 문자열로 유지함. 읍면 경계 밖 인접 정류장도 포함해야 함.
- 익산 `iksan_tago.xlsx`: `노선목록` 시트의 `routeid`, `routetp`, `노선별_정류소` 시트의 `routeid`, `nodeid`, `nodeord`. 추가 사례는 아래 실제 CSV 3종을 사용함. 노선자료가 없으면 노선 수는 결측이며 strict 실행은 실패함.
- `config.json`에서 실제 인구·경계 기준시점과 정류장 수집연도를 확인해 설정함. 수집일을 통계 기준일로 바꾸어 쓰지 않음.
- 정류장 수집범위의 완전성은 자동 증명되지 않음. 다른 시군에 속하지만 가까운 정류장이 누락될 수 있으므로 공급 부족 판정 전 범위를 확인해야 함.

## 새 TAGO CSV의 실제 배치

`data/raw/tago_20261022/{gabuk,yonghwa,gyeolseong,yeonghyeon}/`에 다음을 배치함. `config.json`의 경로는 `data/inputs/`를 기준으로 `../raw/...`를 가리킴.

| 파일 | 필수 실제 열 |
| --- | --- |
| `route_list.csv` | `routeid`, `routeno`, `routetp` |
| `route_stops.csv` | `routeid`, `nodeid`, `nodeord`, `nodenm`, `gpslati`, `gpslong`, `updowncd` |
| `collection_summary.json` | `downloaded_routes`, `stop_records`, `failed_routes` 및 수집시점 |

네 군 도시코드는 TAGO 실제 조회 기준 거창 38390·영동 33340·홍성 34360·경남 고성 38340임. SGIS 읍면동 코드나 군 코드와 동일하지 않음. 당시 도시코드 목록에는 홍성이 없었지만 공식 정류장 파일의 코드로 직접 조회해 노선 응답을 확인함.

`routeid·nodeid·nodeord`에 서로 다른 명칭·좌표 등이 있으면 그 정류장 ID에 연결된 관계 전부를 분석에서 격리함. 홍성 64그룹·48개 ID·128행은 원본과 격리표를 따로 보존함. 완전히 같은 행만 분석용에서 중복 제거할 수 있으며 서로 다른 행 중 첫 행을 선택하지 않음. 현재 네 사례 유효인구 격자 500m 안 기존 정류장 ID 152개는 노선자료와 연결되며 충돌 ID가 겹치지 않음.

동일 ID의 기존 정류장과 API 좌표 최소 차이가 100m를 넘으면 품질검토 대상으로 표시함. 100m는 위험지역 임계값이 아닌 연구자 검토 허용차임. 원 좌표를 새 좌표로 덮지 않음. 연결 미확인·충돌·좌표검토가 있으면 관측 노선 수를 하한으로 표시하고 노선빈곤으로 확정하지 않음. 인접 군 노선 전수 수집·실제 운행빈도는 검증하지 않음.

기존 75,070행 격자인구 표에 값이 있다고 공간분석이 가능한 것은 아님. 제공 GPKG의 전국 결합 레이어에는 실제 공간정보가 익산 주변에만 들어 있었음. 추가지역의 격자 도형을 익산 것으로 대체하지 않음.

새로 신청·다운로드한 공식 SGIS 2025 타일 다바·라라·라마·라바 ZIP의 `GRID_CD`와 기존 인구표의 `grid_id`를 일대일 결합함. 가북면 44·용화면 19·결성면 0·영현면 8격자는 인구표에 미수록되어 결측으로 유지함. 실제 무인인지 비밀보호·누락인지 단정하지 않음. 기록이 있는 0명과 구분함. 신규 경계판에 대한 2024 인구표 결합이므로 2024년의 과거 공간상태를 완전히 복원했다고 주장하지 않음.

공식 국토부 정류장 CSV의 실제 CP949 열을 매핑함: `정류장번호→nodeid`, `정류장명→nodenm`, `경도→gpslong`, `위도→gpslati`. 실제 파일 227,065행(게시 메타데이터 206,022행과 다름), 수집일 모두 2025-10-31. 좌표 범위 이상 12행은 원문 감사표에 남기고 공간계산에서 제외함. 뒤바뀐 좌표를 임의 교정하지 않음. 실제 도시코드는 SGIS와 달라 코드 직접 결합하지 않음.

분석용 정류장은 각 읍면동 500m 외곽권의 모든 점과, 각 격자 중심점에서 전국 수록 자료 중 최근접한 점의 합집합임. 따라서 주변 정류장 수는 행정구역 내부 개수가 아니며 지역 간 버스 공급량 전수 비교용 숫자가 아님. 전국 수록 자료 자체의 누락은 해결되지 않음.

SGIS 격자 이용조건: 출처를 명시하고 연구 완료 후 국가데이터처에 결과물 사본 또는 URL을 제출해야 함. 신청 동의만 완료했으며 연구 결과물 제출은 아직 수행하지 않음. 원자료·경계의 GitHub 재배포 허용을 이 동의로 간주하지 않음.

인구·도로·시설이 같은 기준연도가 아니라는 점과, 읍면동 평균을 격자별 실제 이동시간으로 해석할 수 없다는 점을 유지함. 대상 지역별 로컬 75백분위는 해당 사례 안의 상대 기준이므로 지역 간 절대 위험 수준 비교에 그대로 쓰지 않음. 절대거리 1·3·5km 표를 함께 비교함.
